# Grand Assistant — игровой помощник с плавающим окном

Нативное Android-приложение (Kotlin, minSdk 29 / Android 10, targetSdk 35, работает на Android 10–16, включая Redmi).

## Что умеет
- Главный экран: «Добавить игру» → список установленных приложений → название и версия определяются автоматически.
- «Начать» → запускается плавающая кнопка и открывается Grand Mobile. Вход в аккаунт и выбор сервера — вручную.
- **Плавающее окно (SYSTEM_ALERT_WINDOW / TYPE_APPLICATION_OVERLAY)** — два реальных окна WindowManager:
  - квадратная кнопка с анимированной кошкой; перетаскивается пальцем;
  - тап по кнопке → анимированно открывается большое меню; повторный тап → сворачивается;
  - работает поверх игры в полноэкранном режиме, выход из игры не нужен;
  - положение кнопки сохраняется; можно полностью скрыть кнопку (вернуть — из уведомления или главного экрана);
  - настройки прозрачности и размера.
- Вкладки меню: Заметки, Быстрые команды (копируются в буфер — вставляете в чат сами), Таймеры (сигнал + вибрация + уведомление), Тренировка (мини-режим мишеней внутри панели), Настройки.
- Не трогает сеть, файлы и процесс игры. Пароли не собираются.

## Разрешения
| Разрешение | Зачем |
|---|---|
| SYSTEM_ALERT_WINDOW | только плавающая кнопка и меню |
| FOREGROUND_SERVICE (+ SPECIAL_USE) | чтобы Android не убивал окно во время игры |
| POST_NOTIFICATIONS | уведомление помощника и сигнал таймера |
| VIBRATE | сигнал таймера |

Нет доступа к файлам, контактам, аккаунтам и интернету.

## Сборка APK (Android Studio)
1. Установите Android Studio (Ladybug 2024.2 или новее), JDK 17 идёт в комплекте.
2. `File → Open` → выберите папку `GrandAssistant`. Дождитесь Gradle Sync (нужен интернет, Studio сама скачает Gradle 8.9 и SDK 35).
3. `Build → Build Bundle(s) / APK(s) → Build APK(s)`.
4. Файл: `app/build/outputs/apk/debug/app-debug.apk`.

Из консоли (после открытия проекта в Studio или установки Gradle 8.9):
```
gradle wrapper --gradle-version 8.9
./gradlew assembleDebug
```
Release-версия: `./gradlew assembleRelease` → `app/build/outputs/apk/release/` (подписана debug-ключом для удобной установки).

## Установка на телефон
1. Скопируйте APK на телефон (или `adb install app-debug.apk`).
2. Разрешите установку из неизвестных источников для файлового менеджера/браузера.
3. Откройте Grand Assistant → «Добавить игру» → выберите Grand Mobile → «Начать».
4. При первом запуске разрешите «Поверх других приложений» и уведомления.

## Redmi / Xiaomi (HyperOS / MIUI)
Иначе система может скрывать окно или убивать сервис:
- Настройки → Приложения → Grand Assistant → Другие разрешения → «Отображать всплывающие окна, когда запущено в фоне» — Вкл.
- Автозапуск — Вкл.
- Контроль активности / Экономия заряда → «Нет ограничений».
- Закрепите приложение в списке недавних (замок).

## Структура
- `OverlayService.kt` — foreground-сервис, окна кнопки и панели, drag, анимации, сохранение позиции, уведомление.
- `PanelUi.kt` — содержимое меню (вкладки).
- `TrainingView.kt` — тренировочный мини-режим.
- `TimerManager.kt`, `Prefs.kt`, `Ui.kt`, `MainActivity.kt`.

## Примечания
- Проект написан без доступа к Android SDK, поэтому здесь не компилировался. Если Gradle Sync или сборка покажут ошибку — пришлите лог, исправлю.
- Таймеры живут, пока работает сервис помощника; если Xiaomi убьёт процесс, они сбросятся (см. советы выше).
- Клавиатура в панели: окно становится фокусируемым только на время ввода текста и возвращается в нефокусируемый режим после «Готово» / смены вкладки / сворачивания.
